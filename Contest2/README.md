2. Схема наследования
- InventoryItem
- EnergyConsumer
- Transport <- InventoryItem
- Bike <- Transport
- Helmet <- InventoryItem
- Dock <- InventoryItem + EnergyConsumer
- ElectricScooter <- Transport + EnergyConsumer
- EBike <- Transport + EnergyConsumer

3. Умные указатели
- unique_ptr используется в main при создании новой единицы техники (make_unique). Обеспечивает единоличное владение до прохождения техосмотра. Если ServiceCenter выбрасывает исключение, unique_ptr автоматически уничтожает объект, парк не меняется.
- shared_ptr: Парк хранит принятые единицы техники через shared_ptr. При добавлении unique_ptr конвертируется в shared_ptr (владение передается парку).
- weak_ptr: Используется для витрины. Не увеличивает счетчик ссылок shared_ptr. После команды remove объект удаляется из памяти, и weak_ptr корректно возвращает expired при попытке lock().

4. Исключения
- FleetError <- std::exception, переопределяет what().
- InspectionError — выбрасывается в ServiceCenter::inspect, если есть подстрока "broken" (без учета регистра).
- ParseError — ошибки разбора команд, неверных аргументов.

5. Шаблон
Шаблонный класс Registry<T, Cap> — журнал последних операций (хранит до Cap элементов).
Используется в main для записи истории успешных добавлений техники.

6. Отсебятина
Новый транспорт — EBike (электровелосипед) с командой 'add ebike'
Новый предмет - Dock (док-станция, потребляющая энергию)
Доп. команда novice (выводит транспорт с простотой >= 6) и перегрузка 'operator<<' для печати имени и ID при выводе списка.
